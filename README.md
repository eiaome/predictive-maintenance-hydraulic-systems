# Predictive Maintenance of Hydraulic Systems

## Overview

This project applies machine learning techniques to predict hydraulic system faults using sensor data.

## Models Evaluated

- Decision Tree
- Random Forest
- XGBoost

## Dataset

ZeMA Hydraulic System Condition Monitoring Dataset.

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score

## Features

- Predictive maintenance
- Sensor importance analysis
- Sensor ablation experiments
- Leakage detection
- Diagnostic console

## Repository Structure

- notebook/ : Google Colab notebook
- paper/ : Research paper (Capstone Project for BS Marine Engineering Students)
- app/ : Diagnostic console prototype dashboard
- screenshots/ : Output images
